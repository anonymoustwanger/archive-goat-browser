    Custom filters

    One rule per line, Adblock Plus / uBlock syntax. Examples: ||ads.example.com^ blocks a domain, example.com##.banner hides an element, @@||site.com^ allows it. Lines starting with ! are comments.

    Extensions

    Most Chrome extensions work: ad blockers, password managers, dark mode, and so on. Some APIs aren't available yet (for example chrome.commands), so a few extensions may only partly work. Extension buttons appear next to the shield in the toolbar.

    Proxy

    SOCKS5 sends DNS through the proxy. Chromium doesn't support SOCKS5 passwords: use an HTTP(S) proxy for login-protected servers.

    Clear all browsing dataDeletes cookies, cache, site storage, and closes all tabs. Settings are kept.
